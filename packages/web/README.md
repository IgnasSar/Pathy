# Pathy Web

React + Vite frontend workspace for Pathy.

Current state:

- Tailwind CSS v4 is installed through `@tailwindcss/vite`
- `src/index.css` imports Tailwind with `@import "tailwindcss";`
- `src/App.tsx` contains a minimal page used only to verify the setup

Run locally from the repository root:

```powershell
pnpm dev:web
```
